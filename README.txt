DEMO
Start /demo/workbench/. Review source, normalize units, confirm envelope,
inspect voluntary participation, prepare a nonbinding draft, simulate manager
approval, export a local DEMO draft and inspect the held value report.
45-day proposals are blocked. Consent withdrawal stops progression and
invalidates approval. Term and review-cost changes reset approval.
Permitted reviewer overrides may choose Delta or Juniper when consent holds;
they cannot restore withdrawn consent or bypass prohibited concessions.
All persons, entities, sources, quotes and dates in the demo are fictional.
A simulated approval is not a binding signature. PO issue, ERP writes,
payment, filing, real acceptance and email are disabled.

FORMS & ACCESS
The user explicitly selected preview forms. Nothing is submitted, stored in
browser persistence or sent to an inquiry endpoint. Validation and a local
summary/download work. Form values stay only in page memory until cleared
or reloaded. Marketing-interest selection creates no subscription.
Authentication is not connected and no credentials are collected.

ANALYTICS
Preview events are in-memory and inspectable from the bottom-left control.
Only allowlisted page/offer/source/scenario/campaign values are included.
No email, company, role or free text enters the event list. No network API is
used by application JavaScript. No pilot_request or consent_submit event is
emitted from a preview form, since there is no server acknowledgement.
Clicking or completing the demo is never a paid-pilot or qualified-demand claim.

DOMAIN & COMPANY DETAILS
Private Sites hosting is used for the concept preview. This build does not
connect sourcingrecord.com, create company social profiles or establish
trademark/domain clearance. Real operator/contact/privacy details and actual
service terms remain required before enabling real intake or an operating SaaS.
LinkedIn/Crunchbase footer controls explain the missing verified profile URL.
No real customers, testimonials, certifications, revenue or live integration
claims are included. Pilot pricing is explicitly hypothetical.

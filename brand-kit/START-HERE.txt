INTERACTIONS
Reusable CSS includes default, hover, pressed, focus, disabled, loading,
primary, secondary and reject controls. Main buttons 48px high, radius6,
horizontal padding20, gap12. Focus outline2px/offset3px is immediate.
12 live patterns: text flip, vertical shutter, horizontal shutter, directional
wipe, arrow slot, icon exchange, underline, focus brackets, border rail,
tactile press, limited magnetic face and source drawer.
Use one expressive treatment per page; binding/consent actions stay stable.
Text flips have one stable accessible name and decorative duplicate labels.
Magnetic movement changes the inner face only, max4px, mouse/fine pointer.
Motion supports keyboard and tap feedback; no hover-only critical content.
Reduced motion is available through OS preferences and a kit preview toggle.
